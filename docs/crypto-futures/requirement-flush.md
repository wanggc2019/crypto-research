# 需求：crypto-futures —— 多头出清提醒（资金费率转负 + 账户多空比回落）

> 状态：**已实现，待评审（2026-11-18）**｜上游：[M1 需求](requirement.md) · [M2 需求](requirement-m2.md)（依赖 M2 的实时快照 RT）
> 关联：[消息发送规范](../notify-policy.md)

## 1. 要解决什么问题

急跌之后，用户想知道「多头杠杆是不是已经出清」。两个最直接的持仓结构信号是：

1. **资金费率转负**：永续价格低于现货，空头开始向多头付费，说明多头不再拥挤；
2. **做多账户占比回落**：散户多单被洗掉或主动离场。

2026-11-17 的状态正好相反：BTC 账户多空比 3.08、75% 账户做多且 24h 还在上升，资金费率约 +0.002%。因此要在这两个条件**同时**出现时提醒一次。这是结构信号，**不是**见底判断。

## 2. 规则

| 规则 | 条件 | 级别 | 冷却 |
|---|---|---|---|
| `long_flush` | 实时资金费率（`premiumIndex.lastFundingRate`，即 M2 的 RT 序列）**连续 2 轮 ≤ −0.002%**，且账户多空比（G）**24h 下降 ≥ 10%** | P1 | 12h |

- 评估点 = G 的已收盘 5m 点；资金费率取该点所在（或 10 分钟内最近）的 RT 桶，再往前在 N+1 个连续 5m 桶内找 N 个有费率的样本。样本不足（例如 Mac 休眠空档）就不评估；
- −0.002% 的阈值用来滤掉 −0.0001% 这类贴零噪声（近 90 天 BTC 46 次负结算，大多在 ±0.001% 内）；
- 方向固定为 `down`，幅度 = |G 24h 变化|（用于判断冷却期内是否「加剧」）；
- 治理（冷却、加剧、同轮合并、P0 日上限）沿用 M1。

### 已知限制

- **BNB 的资金费率近 90 天恒为 0**，这条规则对 BNB 实际上不会触发。不为 BNB 单独放宽阈值，以免误报；
- 依赖 M2 的实时 RT 序列，所以要在 PR #45 合并之后上线。

## 3. 卡片

- 标题：「多头出清（费率转负 + 账户比回落）」；
- 结论：「资金费率转负（−0.0030%），24h 内账户多空比下降 20%」；
- 指标：实时资金费率（连续 N 轮 ≤ 阈值）、账户多空比 24h 变化与 7 天位置；
- 解读必须写明「不代表已经见底」；不出现「抄底」「开多」「减仓」等操作建议；
- 口径：Binance USD-M 单所 · 5m 数据。

## 4. 回测（2026-10-20 ~ 11-17，28.5 天，线上 30 天缓存 + `/fapi/v1/fundingRate` 结算记录）

结算记录每 8h 才一条，回测按 `confirm_rounds=1` 评估（`backtest.backtest_cfg`）。结算值本身是 8h 均值，比实时值平滑。

| 资产 | 触发次数 | 时点（本地）与 ETH 之后 24h 涨跌 |
|---|---|---|
| BTC | 0 | — |
| ETH | 5 | 10-30 12:05 +0.4%；10-31 04:00 +0.5%；11-05 04:00 **−7.7%**；11-15 04:00 +3.8%；11-15 20:00 +0.5% |
| BNB | 0 | 费率恒为 0 |

约 0.18 条/天，全模块从 0.56 升到约 0.74 条/天。样本太少，只能说明不会刷屏，不能说明有预测力（11-05 那次之后又跌了 7.7%）。

## 5. 验收标准

1. 单测：费率阈值边界、贴零噪声不触发、需要连续 N 轮（上一轮为正 / 只有 1 个样本 / 空档过长不触发，中间缺 1 轮仍可确认）、G 降幅边界、缺数据与 `enabled: false` 不触发、RT 比 G 晚一个桶时就近取、12h 冷却、卡片文案与禁用词、回测口径 `confirm_rounds=1` 且不改原配置（`tests/test_flush.py`）；
2. `make gate` 全绿；
3. 上线首周看 `make notify-report days=7`：`long_flush` 超过 1 条/天就提高 `g_drop_24h_pct` 或把 `funding_max_pct` 调得更负。

## 6. 回退

`config/rules.yaml` 里 `long_flush.enabled: false`，或 `git revert` 该 squash commit。

## 7. 需要评审的决策

| # | 决策 | 当前取值 | 备选 |
|---|---|---|---|
| D1 | 费率阈值 | ≤ −0.002%，连续 2 轮 | 只要 < 0：BTC 噪声多；≤ −0.005%：30 天 ETH 只剩 2 次，BTC 0 次 |
| D2 | 账户比降幅 | 24h ≤ −10% | −15%：ETH 3 次；−5%：ETH 7–8 次 |
| D3 | 级别 | P1（即时推送） | P2：只落盘不推送 |
| D4 | BNB | 不特殊处理（费率恒 0 不触发） | 对 BNB 只看账户比：会变成另一条规则，误报高 |
